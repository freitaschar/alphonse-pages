Privacy Policy

This application ("Alphonse Workspace Integration") is a personal-use tool built and operated solely by its owner, for the owner's own Google accounts. It is not distributed to or used by any other individual or organization.

Data accessed: with explicit account authorization, this application can read Gmail messages and labels, create (but never send) Gmail drafts, read and create Google Calendar events, and read files in Google Drive, Docs, and Sheets.

Data storage: authorization tokens are stored locally on the owner's own private server and are never transmitted to any third party or external service. No data accessed through these APIs is sold, shared, or disclosed to anyone.

Data retention: cached only as needed for the application's own operation, and deleted upon revocation of access.
